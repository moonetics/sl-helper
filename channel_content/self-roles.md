# PILIHAN ROLE NOTIFIKASI (SELF-ROLES)
Pilih notifikasi yang ingin Anda dapatkan di server Sorevi Labs agar selalu menjadi yang pertama mendapatkan update:
* **Game Updates Ping** — Notifikasi rilis game baru, event menarik, dan update patch besar.
* **Playtest Ping** — Akses awal uji coba (playtest) game baru sebelum rilis ke publik.
* **Sneak Peek Ping** — Bocoran eksklusif teaser dan perkembangan proyek tim developer.
_Klik tombol reaction di bawah pesan ini untuk mengambil atau melepas role notifikasi._
